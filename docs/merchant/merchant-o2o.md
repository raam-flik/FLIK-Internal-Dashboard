# Merchant O2O List

## Overview

The Merchant O2O List module manages merchants participating in the Online-to-Offline (O2O) program. This module allows administrators to add both existing merchants and new merchants to the O2O initiative.

## Features

### O2O Merchant Management

- **View O2O Merchants**: Display list of merchants enrolled in O2O program
- **Add Existing Merchant**: Add already-registered merchants to the O2O program
  - Multi-step selection process
  - Search and filter existing merchants
  - Confirmation workflow
- **Add New Merchant**: Onboard new merchants directly into O2O program
  - New merchant registration within O2O workflow
  - Direct O2O enrollment
- **Multi-Step Workflow**: Guided process for merchant addition with multiple confirmation steps

### Navigation Options

- **Sidebar Sub-items**:
  - Merchant O2O List - View all O2O merchants
  - Add Merchant O2O - Quick add option with plus icon

## Navigation

- **Location**: Main Menu > Merchant > Merchant O2O List
- **Breadcrumb**: Merchant / Merchant O2O List
- **Quick Add**: Plus icon (+) next to "Add Merchant O2O" in sidebar for fast addition

## Page Layout

- **Header**: "Merchant O2O List" title with breadcrumb navigation
- **Action Buttons**: 
  - Add Existing Merchant
  - Add New Merchant
- **O2O Merchant Table**: Display of enrolled O2O merchants

## Workflows

### Adding Existing Merchant to O2O

1. Click "Add Existing Merchant" button
2. Search for and select from registered merchants (Step 1)
3. Select specific merchant to add (Step 2)
4. Confirm addition and complete process
5. Merchant now appears in O2O list

### Adding New Merchant to O2O

1. Click "Add New Merchant" button
2. Fill out new merchant registration form
3. Complete merchant setup
4. Merchant is enrolled in O2O program
