# Merchant Lead

## Overview

The Merchant Lead module allows internal administrators to view and manage potential merchant leads before they become active merchants. This section tracks all incoming leads with their contact information and registration dates.

## Features

### View Merchant Leads

- **Lead List Display**: Shows all merchant leads in a table format
- **Search Functionality**: Search merchants by name using the search field
- **Lead Information**:
  - Brand Name - The business/brand name of the lead
  - PIC Name - Person In Charge contact name
  - PIC Email - Email address of the primary contact
  - Registration Date - Date when the lead was registered
- **Action Options**: View detailed information about each lead

### Lead Details

- Click on "Detail" link to view complete information about a merchant lead
- View lead profile information
- Track lead registration timeline

## Navigation

- **Location**: Main Menu > Merchant > Merchant Lead
- **Breadcrumb**: Merchant / Merchant Lead

## Page Layout

- **Header**: "Merchant Lead" title with breadcrumb navigation
- **Search Bar**: Search merchants field for quick filtering
- **Table Columns**:
  - Brand Name (sortable)
  - PIC Name (sortable)
  - PIC Email
  - Registration Date
  - Action
