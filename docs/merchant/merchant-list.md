# Merchant List

## Overview

The Merchant List module provides administrators with a comprehensive view of all registered and active merchants on the FLIK platform. This module allows for merchant management, status tracking, and profile editing.

![Merchant List Page](../../assets/screenshots/Merchant%20List/Merchant%20List%20Page.png)

## Features

### View All Merchants

- **Merchant List Display**: Displays all registered merchants in a searchable table
- **Search Functionality**: Search merchants by name, company name, or custom domain
- **Add New Merchant**: Quick access button to add new merchants to the platform
- **Merchant Information Displayed**:
  - Company Name
  - Merchant Name
  - Custom Domain
  - PIC (Person In Charge)
  - Status Checkout - Current checkout status (Active/Inactive)
  - Status - Overall merchant status (Active/Inactive)

### Merchant Management

- **Edit Merchant**: Access "Edit" action to modify merchant details
- **Sort by Column**: Click column headers to sort merchants
  - Company Name
  - Merchant Name
  - Custom Domain
  - Status Checkout
  - Status

### Merchant Status

- **Status Checkout**: Indicates if the merchant's checkout system is active or inactive
- **Status**: Overall activation status of the merchant account
- **Visual Indicators**: Status is color-coded (inactive shown in red badge)

## Navigation

- **Location**: Main Menu > Merchant > Merchant List
- **Breadcrumb**: Merchant / Merchant List
- **Sub-items Available**:
  - Merchant Lead
  - Merchant List (current)
  - Add Merchant
  - Merchant O2O List
  - Add Merchant O2O

## Page Layout

- **Header**: "Merchant List" title with breadcrumb navigation
- **Search Bar**: Search merchants field for quick filtering
- **Add Button**: "Tambah" (Add) button for creating new merchants
- **Table Columns**:
  - Company Name (sortable)
  - Merchant Name (sortable)
  - Custom Domain (sortable)
  - PIC
  - Status Checkout (sortable)
  - Status (sortable)
  - Action
