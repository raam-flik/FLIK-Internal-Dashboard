# Add Merchant

## Overview

The Add Merchant module allows internal administrators to create and register new merchant accounts on the FLIK platform.

![Add Merchant Page](../../assets/screenshots/Add%20Merchant/Add%20Merchant%20Page.png)

## Features

### Merchant Registration Form

- **Form-based Input**: Structured form for entering new merchant information
- **Multiple Field Entries**: Capture all necessary merchant details for account creation
- **Form Fields**: Various input fields for merchant setup and configuration

## Navigation

- **Location**: Main Menu > Merchant > Add Merchant
- **Breadcrumb**: Merchant / Add Merchant
- **Access**: Direct link from Merchant List or through sidebar navigation

## Page Layout

- **Header**: "Add Merchant Page" or similar title
- **Form Section**: Complete merchant registration form
- **Submit Button**: Button to create and save new merchant account

## Workflow

1. Navigate to Add Merchant section
2. Fill out the merchant registration form with required information
3. Complete all necessary fields
4. Submit the form to create the merchant account
5. Redirect to Merchant List to confirm creation
