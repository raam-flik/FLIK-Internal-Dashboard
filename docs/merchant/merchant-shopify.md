# Merchant Shopify

## Overview

The Merchant Shopify module allows administrators to manage merchants who have integrated their Shopify stores with the FLIK platform. This module handles Shopify-connected merchant accounts and integration management.

## Features

### Shopify Merchant Management

- **View Shopify Merchants**: Display list of merchants with active Shopify integration
- **Add Shopify Merchant**: Add merchants with Shopify store integration
  - Merchant selection or creation
  - Shopify integration configuration
  - Store connection setup
- **Integration Status**: Track Shopify connection status for each merchant
- **Merchant Information**:
  - Merchant names and details
  - Shopify store information
  - Integration status

## Navigation

- **Location**: Main Menu > Merchant Shopify
- **Breadcrumb**: Merchant Shopify / Merchant Shopify List

## Page Layout

- **Header**: "Merchant Shopify Page" or similar title with breadcrumb
- **Add Button**: "Add Merchant" button to onboard new Shopify-integrated merchants
- **Merchant Table**: List of all Shopify-connected merchants

## Workflows

### Adding Shopify Merchant

1. Click "Add Merchant" button
2. Select or create merchant account
3. Configure Shopify store connection
4. Enter Shopify integration details
5. Complete the integration setup
6. Merchant appears in Shopify merchant list
