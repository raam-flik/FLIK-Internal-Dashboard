# Merchant Cash Advance

## Overview

The Merchant Cash Advance (MCA) module allows administrators to manage business financing and cash advance applications from merchants. This module handles MCA applications, approvals, sales assignments, and tracking.

![Merchant Cash Advance](../../assets/screenshots/Merchant%20Cash%20Advance/Merchant%20Cash%20Advance.png)

## Features

### MCA Application Management

- **View MCA Requests**: Display list of all merchant cash advance applications
- **Application Status Tracking**: Monitor progress of MCA requests
- **Add New MCA**: Create new cash advance applications for merchants
- **Assign Sales Representative**: Assign sales team members to manage MCA applications
- **Detailed Application View**: View complete MCA application details

### MCA Information

- **Application Details**: Track each MCA application
  - Merchant information
  - Requested amount
  - Application date
  - Status (Approved, Pending, Rejected, etc.)
  - Sales representative assignment
- **MCA Status**: Monitor approval and processing status
- **Popup Management**: Quick information popup for MCA details

### Sales Assignment

- **Assign Sales Rep**: Assign specific sales representative to manage MCA application
- **Sales Tracking**: Track which sales rep is responsible for each MCA
- **Sales Rep Management**: Manage sales team involvement in MCA process

## Navigation

- **Location**: Main Menu > Merchant Cash Advance
- **Breadcrumb**: Merchant Cash Advance / MCA List

## Page Layout

- **Header**: "Merchant Cash Advance" title
- **MCA List Display**: Table showing all MCA applications
- **Action Buttons**: 
  - Add Merchant Cash Advance
  - Assign Sales (for existing MCAs)
- **Table Information**: 
  - Merchant name
  - Application amount
  - Application status
  - Assignment status

## Workflows

### Creating New MCA Application

![Add Merchant Cash Advance](../../assets/screenshots/Merchant%20Cash%20Advance/Add%20Merchant%20Cash%20Advance.png)

![MCA Pop Up](../../assets/screenshots/Merchant%20Cash%20Advance/MCA%20-%20Pop%20Up.png)

1. Click "Add Merchant Cash Advance" button
2. Select merchant for MCA application
3. Enter loan/advance amount
4. Set terms and conditions
5. Complete application details
6. Submit MCA application
7. Application appears in MCA list

### Assigning Sales Representative

![MCA Assign Sales](../../assets/screenshots/Merchant%20Cash%20Advance/MCA%20-%20Assign%20Sales.png)

1. Open existing MCA application
2. Click "Assign Sales" button or option
3. Select sales representative from list
4. Confirm assignment
5. Sales rep is now responsible for MCA management
