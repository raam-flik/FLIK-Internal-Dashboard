# Balance Adjustment

## Overview

The Balance Adjustment module allows administrators to manage and adjust merchant account balances. This module handles balance changes, adjustments, and maintains a complete history of all balance modifications.

![Balance Adjustment](../../assets/screenshots/Balance%20Adjustment/Balance%20Adjustment.png)

## Features

### View Balance Adjustments

- **Adjustment History**: Display complete history of balance adjustments
- **Adjustment Records**: View all balance change transactions
- **Adjustment Information**:
  - Merchant information
  - Adjustment amount
  - Adjustment date
  - Adjustment reason/type
  - Previous balance
  - New balance after adjustment

### Create Balance Adjustment

- **Add Adjustment**: Create new balance adjustments for merchant accounts
- **Adjustment Form**: Structured input for balance modifications
  - Select merchant account
  - Enter adjustment amount
  - Specify adjustment type (increase/decrease)
  - Add reason for adjustment
  - Add notes or comments

### Balance Management

- **Increase Balance**: Add funds to merchant account
- **Decrease Balance**: Remove funds from merchant account
- **Adjustment Tracking**: Complete audit trail of all balance changes
- **Merchant Account Impact**: Immediate balance update in merchant account

## Workflows

### Creating Balance Adjustment

![Add Adjustment](../../assets/screenshots/Balance%20Adjustment/Add%20Adjustment.png)

1. Click "Add Adjustment" button
2. Select merchant account for adjustment
3. Enter adjustment amount
4. Select adjustment type (add/remove funds)
5. Provide reason for adjustment
6. Enter any additional notes
7. Review adjustment details
8. Confirm and submit
9. Balance is updated immediately
10. Adjustment appears in history
