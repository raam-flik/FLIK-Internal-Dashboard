# Add Refund

## Overview

The Add Refund module allows internal administrators to create and process new refund requests in the system. This module provides a structured workflow for entering and managing refund transactions.

## Features

### Create New Refund

- **Multi-Step Refund Entry**: Guided process for creating refund requests
- **Refund Form Fields**: Capture all necessary refund information
  - Order information reference
  - Refund details and reason
  - Amount and payment information
  - Status and processing details
- **Step-Based Workflow**: Complete refund process through multiple confirmation steps

## Navigation

- **Location**: Main Menu > Refund > Add Refund
- **Breadcrumb**: Refund / Add Refund
- **Access**: Direct link from Refund List or through sidebar navigation

## Page Layout

- **Header**: "Add Refund" section header
- **Form Section**: Multi-step refund entry form
- **Navigation**: Previous/Next buttons for stepping through refund process
- **Submit Button**: Complete and save refund request

## Workflow

1. Navigate to Add Refund section
2. Enter order information or select existing order
3. Fill out refund details and reason
4. Enter refund amount and payment information
5. Complete multi-step process
6. Review and confirm refund request
7. Submit to create refund
8. Refund appears in Refund List

## Refund Information

The refund creation process captures:
- Related order details
- Refund reason
- Refund amount
- Merchant information
- Customer/shopper information
- Payment method and details
- Refund status
