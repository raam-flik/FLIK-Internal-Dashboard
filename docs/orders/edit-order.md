# Edit Order

## Overview

The Edit Order module allows administrators to modify and update existing order details. This module provides access to edit order information, status, and associated details.

## Features

### Order Editing

- **Edit Order Details**: Modify order information after order creation
- **Update Order Status**: Change order processing status
- **Modify Order Items**: Update items, quantities, or pricing if needed
- **Edit Merchant/Shopper Info**: Update associated merchant or customer information
- **Update Delivery Details**: Modify shipping and delivery information

### Order Information Management

- **Order ID**: Reference and identify orders
- **Order Items**: View and edit ordered products
- **Pricing Information**: Update or correct pricing details
- **Delivery Address**: Modify shipping address
- **Merchant Details**: Update merchant information on order
- **Customer Details**: Update customer/shopper information

## Navigation

- **Location**: Main Menu > Edit Order
- **Breadcrumb**: Edit Order

## Page Layout

- **Header**: "Edit Order" title
- **Order Selection**: Search or select order to edit
- **Edit Form**: Complete order details form with editable fields
- **Save Button**: Submit order changes
- **Cancel Button**: Discard changes

## Workflows

### Editing an Order

1. Navigate to Edit Order section
2. Search for or select order to edit
3. View current order details
4. Identify fields to modify
5. Update order information:
   - Order items or quantities
   - Pricing details
   - Delivery address
   - Order status
   - Merchant or customer information
6. Review changes
7. Save order modifications
8. Order is updated in system
