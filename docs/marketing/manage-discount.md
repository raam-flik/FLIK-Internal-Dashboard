# Manage Discount

## Overview

The Manage Discount module allows administrators to create and manage discount groups and promotional configurations. This module enables the creation of discount categories and community-based promotional groups.

## Features

### Discount Group Management

- **View Discount Groups**: Display all created discount groups and categories
- **Community Groups**: Manage community-based discount groups
- **Group Information**:
  - Group name
  - Discount type
  - Discount percentage or amount
  - Applicable merchants
  - Active status

### Create Discount Group

- **Add Group**: Create new discount group with specific rules
- **Group Configuration**:
  - Set group name and description
  - Define discount amount or percentage
  - Select applicable merchants/communities
  - Set group activation status
  - Configure discount conditions
- **Quick Add**: Popup form for fast group creation

### Community Groups

- **Community Discounts**: Manage discount groups for specific communities
- **Group Organization**: Organize discounts by community or merchant group
- **Targeted Promotions**: Create discounts for specific merchant communities

## Navigation

- **Location**: Main Menu > Manage Discount
- **Breadcrumb**: Manage Discount / Discount Groups

## Page Layout

- **Header**: "Manage Discount" or "Community Group" title
- **Action Buttons**:
  - "Add Group" button for creating new discount groups
  - Popup dialog for group creation
- **Group Table**:
  - Group name
  - Group type
  - Discount details
  - Status
  - Edit/Delete actions

## Workflows

### Creating Discount Group

1. Navigate to Manage Discount
2. Click "Add Group" button
3. Discount group creation popup appears
4. Enter group name and description
5. Set discount amount or percentage
6. Select applicable merchants or communities
7. Configure discount conditions
8. Set activation status
9. Submit group creation
10. Group appears in discount list

### Editing Discount Group

1. Navigate to Manage Discount
2. Find group in list
3. Click edit action
4. Update group details
5. Modify discount settings
6. Save changes
7. Changes take effect immediately
